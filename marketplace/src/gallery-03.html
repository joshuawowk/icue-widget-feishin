Reads your Navidrome server directly

Feishin is a client. This widget asks the server it points at what is playing.

Import
Open the .icuewidget file, or use Widgets, then + in iCUE.
2
Enter your server
Type the Navidrome Server URL, HTTPS recommended.
3
Sign in
Username and password; a dedicated read-only user works well.
Network permission: any host, because the server URL is whatever you type. The server must send CORS headers on /rest (Navidrome does by default). Requires iCUE 5.52 or later.
